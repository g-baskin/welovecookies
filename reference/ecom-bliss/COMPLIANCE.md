# Feature compliance register: Ecom DM

Snapshot: 3 November 2026, local changes on HEAD `1f676e9`. Engineering guidance only, NOT LEGAL ADVICE. This is an inline feature register, not an audit or a certification of the whole store.

## Exposure profile

Confirmed scope: owner-operated keyword-triggered private replies on owned Facebook Pages and professional Instagram accounts. Real comment text and platform identifiers would enter after connection. No real accounts were connected or messaged during development. TikTok sending is absent. Public deployment, customer locations, minors, the owner's entity and final Meta permissions were not verified.

## Release gates still open

1. Resolve the existing store runtime/type/test failures noted in the [implementation record](library/knowledge/private/integrations/ecom-dm.md). The UI fixture alone is not a production-runtime proof.
2. Owner completes Meta app permissions, privacy/deletion setup, deployment and a supervised live delivery test. No agent login, deployment, real DM or account approval was performed.
3. Before resale or distribution, review the actual license/permission documents. Before live messaging, have the appropriate reviewer assess notices, consent wording, retention, deletion and the audiences reached. No jurisdiction-specific legal conclusion is asserted here.

## Not checked

The rest of the storefront's legal posture, existing customer/payment data, deployed analytics, provider dashboards, backup deletion, minors' access and production infrastructure were outside this feature pass. Before live OAuth, verify that tracing and infrastructure logs redact credential-bearing OAuth query parameters (`client_secret`, `code`, `access_token`, `fb_exchange_token`); generic application error messages do not establish that external telemetry is redacted. Re-check this register when the feature, platform rules or release candidate changes.

# Feature compliance register: visitor ID pixel

Snapshot: 3 November 2026, branch `feature/visitor-pixel`, not deployed. Engineering guidance only, NOT LEGAL ADVICE.

The owner supplied an install tag for `px.lspxl.com`. The vendor copy says it identifies ("names") visitors, so it is treated as a person-level identity-resolution tracker. The vendor could not be identified: its domains were registered in June 2026 and their home pages return 404 (checked 2 Nov 2026).
